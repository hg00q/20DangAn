# 体育课程档案网页雏形

请双击 `双击启动体育档案.lnk` 开启本地网站。它会自动打开电脑端 `manage.html` 管理页面。

使用结束后，双击 `双击关闭体育档案服务器.lnk` 关闭本地服务器。档案数据不会被删除。

数据只保存在当前浏览器。请使用页面右上角“导出备份”定期保存备份文件。

GitHub Pages 首页 `index.html` 是手机只读查看页。每次电脑端更新后，在“手机查看发布”页生成 `viewer-data.enc`，再上传覆盖仓库同名文件。手机打开 GitHub Pages 地址，输入查看密码即可只读查看。

请勿将本机备份 JSON、明文成绩表或查看密码上传到 GitHub。
