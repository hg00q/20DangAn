使用提示

  1. 先在“课程与规则”中调整项目选项。
  2. 在“导入成绩”粘贴 Word/Excel 表格。
  3. 同年级、同班、同名自动匹配；其余项目会提示确认。
  4. 完成录入后再发布手机查看数据。

从 Word / Excel 粘贴

复制包含表头的表格后粘贴。识别“姓名、班级、年级”及常用体育项目列；列顺序不必一致。

识别结果

粘贴内容后点击“识别并预览”。

课程与选项

用逗号分隔项目。学生可在档案页随时换项，历史成绩不会被覆盖。

试用版计分规则

当前采用现场项目 8 + 8 + 8 + 6 分，过程性考核 20 分的试用结构。取得正式标准后，可在正式版改为逐档赋分。

学年管理

升级操作会将初一→初二、初二→初三；初三学生转入毕业档案。高中学生仅升年级，不参与中考计分。

手机查看版

发布内容只包含姓名、年级、班级、选项、总评和教师评价；原始导入内容与备份不会上传。

生成后可下载 viewer-data.enc，并上传到 GitHub Pages 仓库。

GitHub 免费发布步骤

  1. 创建一个公开仓库，例如 sports-view。
  2. 上传本文件夹中的 index.html、style.css、viewer.js。
  3. 每次电脑端更新后，把新生成的 viewer-data.enc 覆盖上传。
  4. 在仓库 Settings → Pages 中开启网站；手机打开得到的网址后输入查看密码。

公开仓库只能放网页代码和加密后的查看文件，不能上传本机备份、明文成绩表或密码。
